# Arcade

Fourteen Grok one-shot rooms in one place. Pick a game, a toy, a studio, or a tool.

**Play:** https://habbylabby737.github.io/arcade/

The Way stays at https://habbylabby737.github.io/. Crossing stays at `/crossing`.

## Develop

```bash
cd arcade-src
npm install
npm run dev
```

```bash
npm run typecheck
npm run build
```

The production build writes static files to `../arcade/` with base `/arcade/`.

## Rooms

Games, explore rooms, toys, studios, and tools from the original one-shot repos, without the duplicated auth/server template.
